# Modelado de Ruido en Imágenes Médicas 
Esta tarea analiza diferentes tipos de ruido aplicados a una radiografía de Tórax utilizando Python

Modelos de ruido implementados: 
- Gaussiano
- Salt-and-Pepper
- Speckle
- Poisson
- Ruido tipo interferencia de TV

Fuente del dataset: 
https://www.kaggle.com/datasets/nih-chest-xrays/data
